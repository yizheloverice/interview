# MockInterview 模拟面试区

按 Sean-9/MockInterview.skill 的方法执行（不用安装, 以方法论文档为准）:

1. **输入**: JD + 简历（job-search/02-简历/简历V1-主线版.md 对应岗位版本）
2. **流程**: 命题(隐藏评分标准) → 模拟面(锁定简历动作沿 工具→量级→判断→成果 深挖) → 差距报告(维度雷达/信心盲区) → 弱项复训
3. **存档**: interview_saves/{岗位-slug}.md —— 下次开面先读档, 针对最弱维度复训
4. **节奏**: 第 2 周练习模式+深挖技术; 第 3 周考试模式+Bar-raiser; 每次 45-60 分钟
5. **输出**: 差距报告沉淀到 job-search/03-面试准备/01-简历bullet逐条深挖.md 的对应条目（被问倒的回填）

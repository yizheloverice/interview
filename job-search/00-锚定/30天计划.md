# 30 天求职作战计划（2026-08-28 → 09-28）

第一性原理: **一个月内约到足够面试并拿到合适 offer**。工具全部为手段, 不为工具本身花费时间。

## 工具组合决策

| 环节 | 工具/方法 | 用法 |
|---|---|---|
| 全链路主流程 | get-job.skill 三段链路 | 调研岗位 → 简历改写 → 分轮次面试准备 → 面后复盘题库(99-). 按 SKILL.md + references 的协议执行 |
| 模拟面试训练 | MockInterview.skill | 第 2 周起每周 2-3 场, 练习模式→考试模式 Bar-raiser; 存档 mock/interview_saves/ |
| 简历改写规则 | industry-resume-toolkit `patterns/岗位/开发.md` + 企业性质 patterns | 作为改写规则库引用(量化三段式/个人贡献拆分/技术栈分层), 不安装不修改 |
| 兜底参考 | resume.skill(证据闸门/压测思路) | 定稿前压测清单参考, 不单独跑大流程 |

**不做**: 多工具并行测试目录。30 天窗口内工具轮换是浪费; 每个环节只用一个最强工具, 效果差异以面试结果为准。

## 定位主线

- 简历主线: **AI Agent 平台/代码智能** — MCP 服务 + 四语言代码图谱引擎 + RAG 故障诊断 + Agent 驱动交付(134 commits/1 月)
- 支线叙事: RAG 知识库平台(FaultPro) | LLM 工程化(DPO/ICL/重排)
- 兜底口径: Java/Go 后端(单独 JD 版本, 不重写叙事)
- 城市: 成都为主 + 深圳/杭州/上海为辅(全部视频面)
- 薪资: 期望 30K, 谈判区间 28-35K(AI Agent 岗)

## 每周计划

### 第 0 周(8/28—8/30) · 已启动
- [x] 锚定档案 profile.md
- [x] 工作区与目录建立
- [x] 成都/深圳岗位地图初版

### 第 1 周(8/31—9/6) · 调研深化 + 简历重构
- 岗位地图补全: 40-60 家公司筛选 → A 级 15 家精读 JD, 输出每家的能力关键词/轮次/隐性门槛
- 简历 V1: 按 get-job resume-playbook 五步 + 开发.md 规则重写(主线条目)
- 简历 V1 定稿检查点: 用户逐条确认(改动表 + 追问清单)
- 技术复习启动(每天 1h): MCP 协议 / RAG 全链路 / Go 并发与 GC / Agent 框架(Claude Code 原理/LangGraph) / eBPF 概要
- 产出: 01-岗位调研/*.md, 02-简历/简历V1*.docx, 02-简历/改动说明.md

### 第 2 周(9/7—9/13) · 投递启动 + 面试准备
- 投递: ① 精投 A 级 5 家(官网/内推优先) ② 铺开 30-50 家(BOSS/猎聘; **BOSS 屏蔽现雇主"华为"**)
- 每投一家出 JD 定向版(改动 ≤20%, 不动主线)
- 面试准备: 03-面试准备/00-总览.md + 01-简历bullet逐条深挖.md(每条 bullet: 讲解/追问/证据/兜底)
- 02-表达状态与自我介绍.md(60 秒自我介绍 + 项目逐字稿: 代码图谱引擎 / FaultPro / Agent 交付)
- 第 1 次模拟面试: 练习模式 + 深挖技术
- 产出: 04-投递台账/tracker.csv, 03-面试准备/*.md

### 第 3 周(9/14—9/20) · 面试强化 + 面经
- 模拟面试 2-3 场: 考试模式 + Bar-raiser; 每场出差距报告 → 针对最弱维度复训
- 面经收集: 牛客/脉脉/小红书/offershow(字节/腾讯/蚂蚁/DeepSeek 成都深圳)
- 技术深挖补强: 按 MockInterview 差距报告最弱维度做真题(系统设计: 代码图谱服务如何支撑 Agent; 八股: MCP/工具调用/RAG 优化)
- 若第 1 周复盘无约面 → 检查: 简历是否过筛选(猎头/内推渠道加上), 投递量是否够(换渠道/加猎头)
- 产出: mock/interview_saves/{岗位}.md, 03-面试准备/轮次文件

### 第 4 周(9/21—9/27) · 真实面试 + 复盘迭代
- 目标: 每周 2-4 场真实面试(视频面; 用人单位 HR 协调)
- 每场面后 2h 内填 99-面后复盘题库.md(区分准备/表达/匹配/面试官风格; 被问倒的必回填 bullet 深挖)
- 复盘驱动: 同问题二次被问倒 → 回改简历/话术
- 投递持续铺开(被拒岗位原因→调整目标名单)
- 产出: 99-面后复盘题库.md, 简历 V2(如有回改)

### 第 5 周(9/28 前后) · 谈薪与决策
- 谈薪话术(30K 锚点; OD 经历坦诚话术; 证明 30K 依据: 深圳 Agent 岗均价数据)
- offer 对比矩阵: 城市/薪资/业务/AI 主线相关性
- 决策 + 入职节奏确认
- 产出: 05-复盘/offer对比.md

## 风险与对策

| 风险 | 对策 |
|---|---|
| 在职跳槽 → 面试时间不足 | 每晚 2h + 周末; 约面优先视频+晚间/午休 |
| 成都岗位密度低 | 深圳/杭州/上海并列投; 成都 2-3 家 A 级 + 猎头渠道 |
| OD 背调敏感 | 简历如实写(华为 OD); 面试主动话术; 投递平台屏蔽现雇主关键词 |
| 主线过窄 | 每 JD 可出算法/后端变体; 准备第 6 周后端保底投递 |
| 算法岗(LLM 工程)竞争激烈 | 不作为主线, 仅作为匹配极强时的补充投递 |

## 复盘协议(每周日晚)

- 数据: 投递数/回复数/约面数/面后平均分(自评分)
- 归因: 没约面 = 简历问题(改); 约面被拒 = 表达问题(练); 都做了还没面 = 渠道问题(加猎头)
- 三个决策点: 是否调整主线? 是否降薪档? 是否换城市优先级?
